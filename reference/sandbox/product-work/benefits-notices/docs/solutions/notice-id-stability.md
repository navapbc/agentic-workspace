# Solution: Keep Notice IDs Stable

Fictional example solution note. Shows what belongs in a `docs/solutions/` lane.

Notice IDs (BN-001..BN-140) are referenced by the notice service, analytics, and support macros.
Renumbering breaks all three. To add a notice, allocate the next unused BN-### and record it here;
never reuse or renumber an existing ID.
